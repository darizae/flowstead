## No-leak incident checklist (to follow only if a leak is later confirmed)

1. Contain: disable the leaked key/endpoint publicly.
2. Rotate/revoke in the provider and every dependent service (Supabase, OCI, Vercel, SSH).
3. Check logs, history, artifacts, backup exports for persisted copies.
4. Invalidate sessions (Supabase Auth) as needed; verify sign-outs clear IndexedDB.
5. Redeploy from the fixed commit; verify absence by re-scan before resuming.
6. Notify the owner privately; do not publish exploit detail or a live sensitive URL.
